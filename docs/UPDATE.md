# 更新记录


## v1.8.0

- Mihomo 功能全面去组名化：不再依赖任何组名/配置结构，换订阅、换主机、换规则都不影响
- `/mihomo` 平铺列出全部最底层节点与测速，不出现任何组名
- `/status` 通过真实流量链路（/connections）显示当前节点
- `/switch` 按真实链路或结构自动定位目标组，切换后主组自动联动生效


## v1.7.1

- `/switch` 增加模糊匹配：节点名丢失国旗前缀等也能自动匹配唯一节点并切换
- 多个候选时列出完整节点名供选择，未找到时提示从 `/mihomo` 复制完整名称


## v1.7.0

- `/mihomo` 改为按区域组显示节点与测速（如 香港节点/美国节点/日韩节点/台湾节点/新加坡节点/高级节点）
- 修复内置 REJECT-DROP 幽灵节点导致切换报“未找到该节点”的问题
- 修复主组误选内置 GLOBAL 的问题，切换自动定位到当前手动选择组


## v1.6.0

- 新增 `/ports`：自动列出 Docker 容器、非 Docker 程序（ss 扫描）与手动配置的服务端口，并生成局域网访问地址
- 新增配置项 `PANEL_SERVICES`：手动补充未自动识别的服务（名称=端口）


## v1.5.0

- `/status` 显示 CPU 使用率百分比与温度，并集成网卡与网络流量
- 移除 `/network`、`/traffic`、`/cpu24`、`/mem24`、`/network24`、`/disk_history`、`/logs` 命令
- `/help` 精简并新增切换节点模板
- 修复 `/status` 中 Mihomo 显示上层节点组名的问题，改为显示最底层节点


## v1.4.0

- `/mihomo` 改为只显示最底层节点与测速（连通且 ≤800ms，按延迟升序）
- `/update` 先显示当前版本与最新版本，确认后再升级机器人
- `/switch` 切换成功后显示新节点延迟
- `/help` 重写：每个命令都附带功能说明


## v1.3.0

- `/status` 的 Mihomo 部分改为汇报当前节点与延迟，未开启时显示“未开启”
- `/mihomo` 改为查看可用节点：并行测速，只显示连通且延迟 ≤800ms 的节点
- 新增 `/switch 节点名` 命令切换代理节点


## v1.2.0

- `/status` 全面升级：自动检测主机名和系统版本
- 运行时间、CPU 负载、内存使用率展示更直观
- 新增 Docker 容器列表展示
- 移除 `/cpu`、`/memory`、`/disk`、`/docker` 命令，统一由 `/status` 查看
